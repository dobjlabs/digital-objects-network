# Bitcraft plugin

`plugin.rhai` and `manifest.toml` are generated by `src/main.rs`. Change
recipes in the generator, never in its outputs. To regenerate, run
`cargo run -p bitcraft-pexe-gen` from this directory (it writes into the
current directory), then `cargo run --release -p pexe -- build examples/bitcraft`
from the repository root, which rewrites the manifest's `module_hash`.

## Naming exception: BucketOfBits

Bucket classes are `BucketOf<Resource>` and their actions
`CraftBucketOf<Resource>`, `BucketOf<Resource>Add<n>` and
`BucketOf<Resource>Take1`, with one exception: the bucket of bits is
`BucketOfBits` (`CraftBucketOfBits`, `BucketOfBitsAdd5`, ...), not
`BucketOfBit`. `bucket_class` in `src/main.rs` is the single place that
decides the name. Everything else that names bucket classes or matches them
by pattern must spell it the same way: the icon rules and `CLASS_ART_FILES`
in `presentation/generate.py`, and the rules, values and class order in
`apps/bitcraft/ui/index.html` and `apps/bitcraft/ui/BITCRAFT_SPECIFIC_RULES.md`.

The presentation pack and the Bitcraft UI have their own rules; see
`presentation/README.md`, `presentation/CLAUDE.md` and
`apps/bitcraft/ui/BITCRAFT_SPECIFIC_RULES.md`.
